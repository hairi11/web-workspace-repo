# Roadmap completed through v7

## v1 — Foundation
Ajax, FormAction, Validator, FormSerializer, configuration and URL utilities.

## v2 — Reusable UI/Data
DataTableBuilder, Actions, Repository, ConfirmDialog, Modal and Toast.

## v3 — Generic Advanced Core
Interceptors, cache, retry, timeout, normalized AjaxResponse/AjaxError and reusable configuration.

## v4 — Advanced Forms
Field error renderer, server error mapping, response transform, dirty tracking, reset-on-success and submission state control.

## v5 — Advanced DataTable
Server-side mode, external search, column filters, reusable renderers, selection/bulk-action hooks, refresh/search/destroy APIs.

## v6 — Production Hardening
Request cancellation, request deduplication, configurable retry conditions, EventBus, Logger and request registry.

## v7 — Developer Experience
Stable root exports, examples, API documentation, migration notes, TypeScript declaration file, tests and version metadata.
